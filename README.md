Esse repositório é referente ao Projeto Integrador do 4°Semestre, sendo 2 projetos: 
1. Dashboard de gestão de dados para a ONG Laboratório das Artes:
 Feito para catalogar e gerenciar registros de patrimônios histórico e livros, através de um sistema CRUD.
Tecnologias utilizadas: Java, SpringBoot, MySQL, Spring Web, JavaScript, HTML e CSS.
Arquiteturas utilizadas: CRUD, Padrão Singleton, Factory e MVC

2.Aplicação Mobile para visualização de registros:
 Feita com objetivo de acessar e observar os registros, sem qualquer poder de alteração.

Tecnologias utilizadas: React Native, Node JS, JavaScript, Expo Go e Chocolately
Conceitos: Virtualização e Desenvolvimento Mobile

IMPORTANTE: Para utilizar a aplicação mobile é necessário ter a versão 58 do Expo Go no celular e o Chocolately junto com Node.js no computador

Ao abrir a aplicação mobile, para ter acesso ao banco é necessário estar conectado a mesma internet que o computador e inserir no aplicativo o IP da máquina junto com a porta utilizada (porta 8080)

Exemplo:
http://000.000.00.00:8080
